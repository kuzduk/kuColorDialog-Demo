Ra kuColorDialog is a program for selecting colors, capturing the color of a pixel from the screen, and saving palettes; it includes a screen magnifier and a ruler, both with adjustable scaling.
"Ra" is a standalone program.
"kuColorDialog" is a component for Delphi advanced alternative to the basic TColorDialog  that features the crucial capability of applying the selected color dynamically.

More interesting and useful material on Delphi programming here: https://kuzduk.ru/delphi

Ra kuColorDialog – программа для выбора цвета, захвата цвета пикселя с экрана и сохранения палитр, имеет функцию экранной лупы и линейки, масштаб которых можно настраивать.
Ra – это отдельная программа.
kuColorDialog – это компонент для Delphi, продвинутый аналог примитивного TColorDialog, с важнейшей особенностью в виде динамического применения выбранного цвета.
